## Discussed topics

### Conditional structures practice

The teacher reviewed conditional structures with Luiz through a quiz and various practice exercises.

- Details
    
    - Be: Explained the difference between different types of conditionals, focusing on "if I had" vs. "if I had had" structures
    - Luiz: Completed quiz questions about conditional sentences
    - Be: Provided examples to clarify when to use "would" vs. "would have" in conditional sentences
    - Luiz: Practiced forming sentences with both simple and complex conditional structures
- Conclusion
    
    - There are different types of conditional structures that require different verb forms
    - When using two past verbs in the condition, the result requires "would have" + past participle
    - When using one past verb in the condition, the result uses "would" + base verb

### Real-life application of conditionals

The teacher created hypothetical scenarios for Luiz to practice using conditionals in conversation.

- Details
    
    - Be: Asked questions like "What would you do if you won $1 million?"
    - Luiz: Responded that he would travel abroad
    - Be: Asked about what Luiz would have done if he had traveled abroad as a child
    - Luiz: Practiced forming responses using both "would" and "would have" structures
- Conclusion
    
    - Conditional structures can be used to discuss hypothetical present/future scenarios (would) and hypothetical past scenarios (would have)
    - Practice with real-life examples helps reinforce the grammatical patterns

### Historical vocabulary

The teacher introduced vocabulary related to historical and medieval contexts.

- Details
    
    - Be: Asked Luiz how to say various terms in English, such as "defeat an army," "attack a fleet," and "fight a battle"
    - Luiz: Successfully identified some terms like "fleet" which he was familiar with from work
    - Be: Introduced architectural terms like "cathedral," "abbey," and "dome"
    - Be: Explained the difference between "Tower of London" (specific) and "London Tower" (generic)
- Conclusion
    
    - Historical vocabulary can be useful for discussing historical events or when traveling
    - Some terms have specific usage rules that differ from general patterns
